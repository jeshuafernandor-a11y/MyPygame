1. ¿Qué es Pygame y para qué se sirve?
Es un conjunto de librerías para Python que nos sirve para crear videojuegos de forma más sencilla. Básicamente nos evita tener que programar todo el motor gráfico desde cero,
 ayudándonos a manejar con facilidad las ventanas, los gráficos, los sonidos y lo que tecleamos o movemos con el mouse.

2. ¿Cómo se relaciona Pygame con lo que vemos en clase?
Los ciclos (while): Los usamos para mantener el juego corriendo a cada instante (fotograma por fotograma), actualizando lo que pasa en la pantalla sin que se cierre de golpe.
Los eventos: Sirven para atrapar las acciones que hacemos mientras jugamos, como presionar una tecla, mover el ratón o cerrar la ventana (pygame.event.get()).
Estructuras de datos y funciones: Las aplicamos para organizar mejor el código; por ejemplo, usando listas o diccionarios para guardar varios elementos a la vez (como enemigos o puntos) y funciones para separar la lógica de cuándo choca un objeto o cuándo se dibuja.

 3. ¿Qué significa que Pygame permite "tomar mucho o poco" de la librería?
Quiere decir que es una herramienta muy flexible. Puedes hacer algo súper sencillo con poquitas líneas de código para abrir una ventana básica ("poco"),
 o aprovechar toda su potencia avanzada para manejar sistemas complejos de imágenes, colisiones y físicas cuando estás armando un juego más grande ("mucho").
